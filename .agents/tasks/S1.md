2. **`Tools/SpikeHarness/`** — standalone SPM executable (own Package.swift, path

   other deps). `main.swift` (+ helpers as needed):
   - Args: `--order sck|mic` · `--vp on|off` · `--duration 600` · `--label NAME` ·
     `--probe` (permissions only) · `--tone-path` (default /tmp/scribe-spike-tone.wav).
   - **Permissions phase**: preflight mic (`AVAudioApplication.shared.recordPermission`)
     + screen (`CGPreflightScreenCaptureAccess`). Mic not granted →
     `requestRecordPermission`, await, still denied → print instructions, exit 10.
     Screen false → `CGRequestScreenCaptureAccess()` (triggers prompt/System Settings),
     re-preflight after; still false → print exact instructions (grant for the
     responsible app under System Settings → Privacy & Security → Screen Recording,
     then RERUN), exit 11. `--probe` does exactly this phase then exit 0.
   - **System-audio source**: child `afplay <tone>` process (SEPARATE process — the
     engine sets `excludesCurrentProcessAudio`, so the harness's own audio would be
     excluded). Generate the tone WAV by hand (RIFF header + 16-bit PCM, ~30 s,
     440 Hz amplitude-modulated at LOW volume) at startup if missing; restart afplay in
     a loop while the run is active; kill it at the end.
   - **Run**: build `SCKCaptureEngine(config:)` per args; collect per-channel stats via
     `onAudio`: buffer count, total samples, first-arrival delay (monotonic since start),
     last-arrival time, max inter-buffer gap WHILE the stream is alive, 10 s timeline
     snapshots → JSONL on stderr. Capture `onRemoteDegraded` (reason + time) and
     `onDeviceChange` (count). Thread-safe stats (lock or atomics — callbacks arrive on
     engine queues). Main thread blocks on a semaphore for `--duration`, then
     `engine.stop()`, kill afplay, emit verdict.
   - **Verdict JSON on stdout** (single line, machine-readable):
     `{label, order, vp, durationSec, ok, mic: {buffers, firstArrivalMs, maxGapSec},
     remote: {...}, remoteDegraded: String?, deviceChanges: Int, notes: [String]}`.
     ok = BOTH streams delivered ≥ 50 buffers, first arrival < 5 s, maxGap < 10 s, no
     degradation. Include a `swiftRuntimeNote` if VP enable failed (engine falls back).
   - Log a plain-English progress line every 30 s to stderr.
