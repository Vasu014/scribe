## What exists (wire to it — do not reinvent)
- `SessionCoordinator.attach(FragmentComposer)` — sets up store persistence; the panel
  drives `composer.edit/newline/heartbeat` with `coordinator.nowOffset()`.
- `FragmentComposer` — pending-row composer (1s debounce persist, 3s burst freeze);
  callbacks `onPersistPending`/`onFreeze` are CONSUMED BY THE COORDINATOR via attach —
  the panel must NOT overwrite them. The panel's own "saved" feedback comes from
  observing persistence differently: subscribe to nothing — instead have ScribeApp wire
  a SECOND signal: `composer.onPersistPending` is coordinator-owned, so ScribeApp will
  pass a `onPersisted: (() -> Void)?` callback INTO the panel, called by the app from a
  wrapper it installs around the store (simplest correct approach: the app polls
  nothing; instead the panel shows the tick when ITS debounce fires locally — drive the
  tick off the panel's own text-did-change debounce timer (~1s), matching the composer's
  persist cadence; document this coupling honestly).
- `coordinator.displayState` / `CoordinatorEvent.stateChanged(.recording)` — recording
  vs no-meeting state.
- `GlobalHotkey.onSummon` — ScribeApp routes it to the panel (`toggle`).
- Design: dark HUD (primary): NSVisualEffectView hudWindow material, 0.5pt white-14%
  border, radius 12, ~306pt wide, min height ~150; header 10/12 padding hairline; body
  13pt system font line-height ~1.55 white-85% on dark; light variant NOT needed (HUD
  primary per design 1b; note 1c exists).
- `Formatting.elapsed` helper exists.

## Deliverables (App/)

1. **`ScratchpadPanelController.swift`** — NSPanel (.nonactivatingPanel | .titled off |
   .resizable off, .hudWindow level = floating + NSWindow.Level.floating; collection
   behavior: canJoinAllSpaces, fullScreenAuxiliary) — floats above, never steals focus:
   - Header: pulsing 7pt red dot + elapsed (SF Mono 12 tabular, wall clock via timer
     asking `coordinator.elapsed()`), hotkey hint "⌥⌘N" 11pt white-35%, Stop button
     (text systemRed-ish on 16% fill, radius 6) → `coordinator.stop()`.
   - NO-MEETING state: dot white-25% static, label "No meeting" white-50%, Start
     Meeting button (blue system fill) → `coordinator.start()` (errors logged), body
     hint text "Fragments typed here are discarded unless a meeting is recording."
     (typing in this state does NOT reach the composer — no session).
   - Body: bordered-less NSTextView, placeholder "Jot a fragment — plain text, saved as
     you type" (32% white). Rich text OFF. Caret accent color.
   - Text → composer: on textDidChange send full text with
     `coordinator.nowOffset()`; newline key (Enter) → `composer.newline(at:)` AND clear
     the view (burst boundary; fragments are one-burst-per-line UX — document); 100ms
     heartbeat timer → `composer.heartbeat(at:)` while visible.
   - Saved tick: "Saved" 11pt white-45% fades in ~1s after the panel's own typing
     debounce fires, fades out after 2s (design 2e); no spinner.
   - Visibility: toggle via `toggle()` (hotkey); Esc dismisses (keyDown via
     performKeyEquivalent or local monitor scoped to the panel — no global NSEvent
     monitor); recording continues (menu bar dot unaffected). Summon animation 180ms
     ease-out opacity 0→1 + scale .96→1 (anchor top-center), dismiss 140ms; Reduce
     Motion → fade only. `orderFrontRegardless()` (non-activating).
   - Panel updates header state from coordinator events (recording ⇄ idle etc.).
   - Show elapsed via timer 1s while recording; stop timer when hidden.

2. **ScribeApp wiring** (edit): create panel controller after coordinator; `attach` a
   FragmentComposer instance owned by the app; route `GlobalHotkey.onSummon` → panel
   `toggle()`; pass coordinator events to panel (recording state). Start Meeting/Stop
   from the panel reuses coordinator; the menu bar already renders states.

3. **`Formatting.swift`** — extend ONLY if you need a shared color/metric constant;
   otherwise keep local.
