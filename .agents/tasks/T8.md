EFFICIENCY: `make build` once at end; short report ≤ 20 lines.

## What exists
- `PermissionStatus` (CaptureKit): mic/screen enum + async request wrappers
  (CGRequestScreenCaptureAccess triggers the TCC prompt).
- `ModelDownloadManager` (TranscribeKit): variant → AsyncStream<progress 0–1 |
  completed | failed>.
- `KeychainStore` (FusionKit): save/load/delete API key.
- `SCKCaptureEngine` + `WhisperKitTranscriber` + `WhisperKitEngine` — the real engines.
- `UserDefaults` keys: `whisperModel` (default small.en), `lookbackSeconds` (20).

## Deliverables (App/)

1. **`SetupWizardController.swift`** — simple 5-step sheet/panel flow, persisted phase
   (UserDefaults `setupPhase` int; phase names documented). Steps:
   (0) welcome: what Scribe does, both permissions explained BEFORE any prompt (SPEC
   §4.1: explain both prompts before triggering them);
   (1) mic: request → status;
   (2) screen recording: CGRequestScreenCaptureAccess → note "requires quit & reopen if
   newly granted" (TCC relaunch, SPEC §4.1) — show relaunch instruction; Continue
   assumes relaunch happened or permission pre-existed; re-check on appear;
   (3) model download: ModelDownloadManager for UserDefaults whisperModel with progress
   bar; skip if isDownloaded; failure → retry;
   (4) API key: secure field + save to Keychain; skip allowed (fusion retries later
   with clear error); Done → phase 5 (never show again). Back/skip where sensible;
   Cancel just closes (phase persists). Window ~440pt, plain AppKit, grouped style to
   match Settings.

2. **Real wiring in `ScribeApp`** (edit):
   - Engine: replace StubCaptureEngine with SCKCaptureEngine (voiceProcessing default
     true); onDeviceChange → coordinator.handleDeviceChange(); onRemoteDegraded → log +
     (later surface; TODO note). Keep stub available behind a UserDefaults debug flag
     `debugUseStubCapture` (Bool, default false) for UI development without TCC.
   - Transcriber: WhisperKitTranscriber with WhisperKitEngine for the persisted model
     (build lazily — model load is slow; if model folder missing at first session start,
     fall back to UnimplementedTranscriber + log; wizard normally prevents this).
   - First run: if `setupPhase` < 5 → show wizard on launch (after menu bar ready).
   - Start flow guard: if mic or screen permission missing when user starts a meeting,
     open wizard at the relevant step instead of failing silently.

3. **`MenuBarController` small edit** if needed for the start-guard (e.g. callback when
   Start clicked pre-permissions) — keep minimal.
