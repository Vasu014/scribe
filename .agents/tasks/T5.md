## Deliverables (all under App/)

1. **`ScribeApp.swift`** (REWRITE the placeholder): AppDelegate + `NSStatusItem` setup;
   app wiring in one place: open store (in-memory fallback if default fails — document),
   build coordinator with StubCaptureEngine + UnimplementedTranscriber +
   defaultFusionRunner(KeychainStore-backed provider). Subscribe to coordinator events.
   Activation policy stays accessory (LSUIElement already set).

2. **`MenuBarController.swift`** — NSStatusItem + NSMenu per design/README "Menu bar item":
   - States (derived, SPEC §5): idle (template waveform glyph — draw 4 rounded bars via
     NSBezierPath in an NSImage, template mode), recording (capsule: pulsing 7pt red dot +
     SF Mono tabular elapsed from `coordinator.elapsed()`, 1 s timer), processing
     (NSProgressIndicator small spinner), done (transient 4 s: green check + "Notes ready",
     clickable → opens History window if exists else no-op with TODO, then revert to
     idle), failed (persistent ⚠ until menu opened; menu gains "Retry Fusion" item →
     coordinator.retryFusion()).
   - Menu: Start Meeting / Stop Meeting (elapsed right-aligned while recording) ·
     Open Scratchpad ⌥⌘N (disabled placeholder — panel is T6; leave action TODO) ·
     History… (disabled placeholder — T7) · Settings… ⌘, · Quit ⌘Q.
   - Recording indicator ALWAYS visible while capturing (design: non-negotiable).
   - Dot pulse 1.6 s opacity cycle; respect NSWorkspace.accessibilityDisplayShouldReduceMotion.

3. **`SettingsWindowController.swift`** — ~520pt window, System-Settings grouped-card
   style per design 1e: (1) Anthropic API Key — masked ••• display + secure edit-in-place,
     save/delete via KeychainStore, caption "Stored in the macOS Keychain";
   (2) Whisper Model — popup: tiny.en / base.en / small.en (default) / large-v3-turbo
     (title "large-v3-turbo (large download)"); selection persisted to UserDefaults
     (key documented); applies next session (caption); (3) Lookback Window — popup 20
     seconds (default) / 10 / 30 / 60, caption "Advanced — how far back fusion anchors a
     fragment in the transcript"; persisted; (4) Launch at Login — NSSwitch via
     SMAppService.mainApp register/unregister, current status reflected.
   No SwiftUI unless trivially cleaner — AppKit preferred for the panel/window shells.

4. **`GlobalHotkey.swift`** — Carbon RegisterEventHotKey ⌥⌘N (kEventHotKeyModifiers
   optionKey|cmdKey, kVK_ANSI_N); callback posts to main queue → toggles the scratchpad
   panel (T6 — call a registry closure `onSummon: (() -> Void)?` set by the app; log
   no-op if unset). Unregister on dealloc. No NSEvent global monitors (SPEC §5).

5. **`Formatting.swift`** — small helpers: elapsed mm:ss / h:mm:ss (SF Mono tabular via
   NSFont.monospacedDigitSystemFont), used by menu bar + later panels.
