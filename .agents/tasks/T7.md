## What exists (wire to it)
- `MeetingStore` — allSessions(), session(id:), segments(sessionId:),
  fragments(sessionId:), canonicalNote(sessionId:), deleteSession(id:).
- `CoordinatorEvent.recoveredSessions` + session row `recovered` flag + `title` +
  `state` (recording|processing|complete) + `startedAt/endedAt`.
- `NotesValidator.validate(markdown:segments:)` — re-run on display for inline warnings
  (deterministic, cheap — no stored findings needed).
- `EvalCase.build(...)` (FusionKit) + JSON encoding; `KeychainStore` n/a here.
- `coordinator.retryFusion(for:)`; `coordinator.currentSession`.
- `CanonicalRendering.renderTranscript(_:)` for the raw transcript view + export.
- `Formatting.elapsed`.

## Deliverables (App/)

1. **`HistoryWindowController.swift`** — standard titled window ~760×470 (design 1d),
   NSSplitView-style: LEFT sidebar 236pt source-list: rows = title (or "Untitled" /
   date-duration fallback) 13pt medium truncating + right meta 11pt ("42 min" | spinner
   + "fusing" | "failed" red #E0483E; "recovered" yellow tag capsule when
   session.recovered), second line date 11pt. Data: reload on window open + on
   coordinator events (stateChanged/fusionFindings/fusionFailed) + 1s timer while a
   fusing row exists. RIGHT detail: toolbar (Notes | Transcript segmented control;
   Export / Retry Fusion / Export Eval Case / Delete bordered buttons, Delete text red);
   content per design 1d: title 17pt semibold, meta line "Today, 9:00–9:42 AM · fused
   from N fragments" (build a small relative-date formatter), rendered markdown
   (NSViewWithAttributedText is fine — headings/bold/bullets minimal renderer; no
   third-party deps; document limitations), validator warning cards INLINE in the notes
   flow (yellow 12% fill card, radius 7, ⚠ + 12pt text, per finding), action items as
   STATIC checkbox glyphs (square + border, non-interactive — v0 stores no done-ness).
   Transcript view: monospaced 12pt rendering via CanonicalRendering.renderTranscript.
   EMPTY state (design 2d): centered gray waveform glyph + "No sessions yet" + caption +
   bordered Start Meeting button → coordinator.start() (errors logged).
   - Actions: Export → NSSavePanel .md (notes + collapsible transcript: markdown with
     <details><summary>Transcript</summary> + fenced text; document format); Retry
     Fusion → coordinator.retryFusion(for: selected) enabled only for state ==
     .processing; Export Eval Case → enabled when canonical note exists; optional
     corrected-output prompt sheet (text field + Save) → EvalCase.build + JSONEncoder
     (prettyPrinted) → NSSavePanel .json; Delete → NSAlert confirm → store.deleteSession
     + list reload.
   - Selection persistence (last selected session id in UserDefaults) — small touch,
     cheap.

2. **`ScribeApp`/`MenuBarController` wiring (edits)**: HistoryWindowController owned by
   app, lazily shown (menu History… enabled now; menu-bar done-badge onOpenHistory →
   show + select that session — the done event carries sessionId).

3. **`MarkdownMiniRenderer.swift`** (App/) — minimal attributed-string markdown for the
   notes pane subset: #/##/### headings, bold/italic spans, - bullets, [USER-note-free];
   keep it tiny and documented as display-only (not a general markdown lib).
